About

VIDAA Launcher is a remote-friendly home screen for websites and web apps on Hisense / Toshiba VIDAA TVs. VIDAA is not Android, so Android apps (APK files) cannot be installed or run. For those, plug an Android TV / Google TV stick into an HDMI port.

Remote keys: Arrows move · OK selects · BACK goes back · RED = app options · GREEN = add app · YELLOW = edit mode · BLUE = settings · 1–9 / 0 = quick-launch app 1–10.
